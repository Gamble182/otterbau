📱 So installierst du die Icons:

  1. Lade alle 3 PNG-Dateien herunter
  2. Ersetze die Dateien in deinem public/ Ordner
  3. Committe und pushe zu GitHub: git add public/ && git commit -m "Update app icons" && git push
  4. Nach dem Vercel-Deployment kannst du die App auf deinem iPhone hinzufügen!
